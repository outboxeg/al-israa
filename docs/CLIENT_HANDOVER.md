### 🛠️ 4. دليل استخدام لوحة التحكم (CMS User Guide)

#### أ. التقسيم المبوب حسب الصفحات (Page-by-Page Editing):
تحتوي لوحة التحكم على شريط جانبي مقسم حسب صفحات الموقع الـ 7:
1. **🏠 1. الصفحة الرئيسية:** تعديل نصوص وصور الهيرو، إحصائيات الأثر، بيانات المدارس الخضراء Outbox، إضافة/تعديل/حذف الأخبار والفعاليات، والتحكم في شركاء النجاح.
2. **🛒 2. متجر التبرعات:** تعديل ترويسة المتجر، إضافة حملات وأسهم جديدة، تعديل أسعار الأسهم، المبالغ المستهدفة، والمبالغ المجمعة مع رفع صور الحملات.
3. **🏥 3. مجمع الإسراء التنموي:** تعديل نبذة المجمع، وتفاصيل وأنشطة كل طابق من الطوابق الخمسة.
4. **🛏️ 4. دار ضيافة الأورام:** التحكم في السعة الاستيعابية للأسرة، شروط ومعايير الاستقبال المجاني، ومعلومات الاتصال بالطوارئ.
5. **💼 5. المشروعات والتمكين:** إدارة بيانات مشروع تروسيكلات أرزاق، مشاغل النول والسجاد، والتعليم المجتمعي.
6. **💳 6. إتمام التبرع والحسابات:** تعديل أرقام حسابات البنك الأهلي وبنك مصر، أرقام محافظ فودافون كاش، ومعرف إنستاباي IPA.
7. **📍 7. تواصل معنا وخريطة المقر:** تحديث عنوان المقر، كود خريطة جوجل دمنهور، ورابط الـ GPS المباشر.

#### ب. منشئ البلوكات المرن (WordPress-Style Block Builder):
- في نهاية كل صفحة داخل لوحة التحكم، يتوفر نظام لبناء المحتوى الإضافي.
- يمكنك إضافة **بطاقة محتوى (Card)**، **فقرة نصية (Text)**، **صورة وميديا (Media)**، أو **عنوان بارز (Heading)** لأي صفحة، ويتم حفظها وانعكاسها فوراً على الموقع.

#### ج. صندوق الطلبات والاستفسارات الواردة (Inbox):
- يستقبل كافة حجوزات دار ضيافة الأورام، استفسارات التواصل، وطلبات التدريب المهني.
- مزود بزر **"تصدير لملف CSV / Excel 📄"** لتنزيل قائمة المستفيدين بضغطة زر واحدة.

#### د. النسخ الاحتياطي السحابي الشامل (Backup & Restore):
- **تحميل نسخة احتياطية (Export JSON):** ينشئ ملفاً يحتوي على كافة صفحات الموقع، التعديلات، الأخبار، والحملات لحفظها كأرشيف أمان.
- **استعادة نسخة سابقة (Import JSON):** استرجاع الموقع بالكامل بنقرة زر واحدة في حال الانتقال لجهاز آخر.
- **الربط السحابي مع Google Sheets:** حقل لإدخال رابط Webhook مجاني لحفظ كافة استمارات الموقع في شيت جوجل أونلاين تلقائياً.

### 🌐 5. منظومة الترجمة والتبديل ثنائي اللغة (Bilingual Localization)
- **اللغة الافتراضية:** اللغة العربية (`dir="rtl"`).
- **التحويل للإنجليزية:** بمجرد النقر على زر `🌐 English` في الترويسة العلوية، يتم تحويل الموقع **كاملاً 100%** (جميع الصفحات الـ 7 + لوحة التحكم CMS + النماذج + النوافذ المنبثقة + سلة التبرعات) إلى اللغة الإنجليزية مع ضبط الاتجاه (`dir="ltr"`).
- **الحفظ التلقائي:** يتم حفظ لغة المستخدم المفضلة في ذاكرة المتصفح (`localStorage`) لتبقى مفعلة أثناء التنقل بين الصفحات.

---

### 📱 6. التوافق الشامل مع كافة الأجهزة (Mobile & Responsive Optimization)
- **الهواتف الذكية (Smartphones):** أزرار ترويسة ذكية مانعة لالتفاف النصوص (`white-space: nowrap`)، قائمة تنقل جانبية سلسة (Mobile Drawer)، وأزرار عائمة للتبرع والواتساب.
- **الأجهزة اللوحية (Tablets / iPads):** تحويل القائمة تلقائياً عند عرض 1024px لمنع ازدحام الروابط وشبكة كروت متوازنة.
- **الشاشات الكبيرة والحواسيب المحمولة:** توزيع فسيح مع هوامش مريحة وأعلى درجات الوضوح والتباين البصري.

### 🚀 7. إرشادات الرفع والنشر (Deployment Instructions)
1. **استضافة GitHub Pages (موصى بها):**
   - المشروع مهيأ بملف `.nojekyll` لضمان قراءة كافة الملفات والأيقونات دون أي معالجة إضافية.
   - يتم النشر على فرع `main` مباشرة.
2. **استضافة cPanel أو خادم خاص:**
   - انقل كافة الملفات الموجودة داخل مجلد `website/` مباشرة إلى المجلد الرئيسي للموقع (`public_html` أو `www`).
   - لا حاجة لتثبيت أي قواعد بيانات أو حزم Node.js/PHP؛ الموقع يعمل تلقائياً وبشكل كامل فور رفع الملفات.
