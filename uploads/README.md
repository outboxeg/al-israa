# 📁 مجلد الملفات المرفوعة من لوحة التحكم (CMS Uploads Directory)
### Al-Israa Charity Association - Media & Uploads Folder

---

## 📌 نبذة عن هذا المجلد (About this directory):
يحتوي هذا المجلد على الصور والملفات التي يتم رفعها أو أرشفتها عبر لوحة التحكم (CMS) لموقع جمعية الإسراء الخيرية بدمنهور.

## ⚙️ آلية عمل رفع الملفات في لوحة التحكم (Upload Engine Mechanism):
1. **الرفع المباشر والضغط الذكي (Client-Side HTML5 Canvas Compression):**
   - عندما يقوم مسؤول لوحة التحكم باختيار صور من هاتفه أو حاسوبه (للأخبار، أو حملات التبرع، أو الشركاء)، يقوم النظام تلقائياً بضغط الصور وتحجيمها بما لا يتعدى 800 - 900 بكسل بنقاء 82%.
2. **التخزين المشفر (Base64 Safe Storage):**
   - يتم تحويل الصور إلى بيانات Base64 مشفرة وحفظها محلياً في `localStorage` والنسخ الاحتياطية.
   - يتيح هذا للمسؤول غير التقني تشغيل الموقع وإضافة الأخبار وتحديث الحملات ونشر الصور فورياً دون الحاجة لفتح GitHub نهائياً.
3. **الأرشفة والتوثيق (Uploads Archive & Manifest):**
   - يتم توثيق كافة الملفات في ملف الأرشيف العام [`cms_uploads.json`](../cms_uploads.json).
   - يمكن لمسؤول النظام تصدير حزمة الملفات أو تحميل ملف `cms_uploads.json` من تبويب "النسخ الاحتياطي والربط" في لوحة التحكم.

## 🗂️ التسميات والأنواع المدعومة:
- الصور: `JPG`, `PNG`, `WEBP`, `SVG`.
- وثائق وإشعارات التبرع: `PDF`, `JPG`.
